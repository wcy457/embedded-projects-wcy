# 智能锁项目

基于 STM32F103 的智能门锁，按功能模块分课时递进实现，最终集成语音播报。

## 硬件平台

- **MCU**：STM32F103（标准外设库 StdPeriph_Driver）
- **指纹模块**：MG200
- **存储**：AT24C04（EEPROM）
- **触摸**：BS8116A 触摸按键 IC
- **通信**：串口、蓝牙
- **执行**：门锁电机
- **其他**：OLED 显示、RTC、语音播报

## 功能模块（对应目录）

| 目录 | 功能 |
|---|---|
| `1、点灯` | GPIO 点灯入门 |
| `2、OLED(寄存器SPI)` / `2、OLED(模拟SPI)` | OLED 显示驱动 |
| `3、usart` | 串口通信 |
| `4、蓝牙配置` | 蓝牙模块配置 |
| `5、AT24C04` | EEPROM 存储 |
| `6、RTC` | 实时时钟 |
| `7、触摸按键` | BS8116A 触摸按键 |
| `8、用串口1对指纹模块进行测试` | 指纹模块测试 |
| `9、指纹模块MG200` | 指纹识别 |
| `10、门禁卡` | RFID 门禁卡 |
| `11、门锁电机` | 电机驱动开锁 |
| `12、语音播报` | 语音播报（最终集成工程） |

## 目录结构（单个课时）

```
课时目录/
├── HARDWARE/    # 硬件驱动
├── SYSTEM/      # 系统文件（sys、usart）
├── USER/        # 应用代码（test.c）
└── STM32F10x_StdPeriph_Driver/  # 标准外设库
```
