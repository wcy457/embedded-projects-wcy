# 智能冰箱

基于 STM32F103 的智能冰箱控制系统，采集温湿度并通过 OLED 显示，支持旋转编码器调温、PWM 调速、开门超时报警以及串口远程控制。

## 硬件平台

- **MCU**：STM32F103
- **温湿度传感器**：DHT11
- **显示**：OLED
- **输入**：旋转编码器、独立按键
- **执行**：PWM 电机（压缩机/风机）、蜂鸣器、LED
- **通信**：USART 串口

## 功能特性

### 1. 温湿度采集与显示
- DHT11 实时采集温度、湿度
- OLED 四行显示：实时温度、设定温度、湿度、门状态、开门次数、当前时间

### 2. 温度闭环控制
- 旋转编码器调节设定温度（范围 20~30°C，步进 0.5°C）
- 根据温差 `diff = 当前温度 - 设定温度` 比例调节 PWM 占空比
- 温差 ≤ 0.5°C 时电机停止，温差越大转速越高（上限 100%）

### 3. 门状态管理
- 按键切换门开/关状态
- 开门次数累计统计
- 记录最近一次开门时间（RTC）

### 4. 超时报警
- 开门持续超过 10 秒触发蜂鸣器间歇报警
- 串口输出 `[WARN] Door Open Too Long!` 警告日志

### 5. 串口远程控制
- `SETxx`：远程设定温度（xx 为 20~30）
- `GET`：查询当前温湿度、设定温度、门状态
- 每秒定时上报 `[LOG] T=xx.x Set=xx.x Door OPEN/CLOSED`

## 系统流程

```
主循环:
  DHT11 采集温湿度 → OLED 显示
  编码器调节设定温度 → PWM 比例调速
  按键切换门状态 → 计数/计时
  开门超时检测 → 蜂鸣器报警 + 串口警告
  串口命令解析 → 远程设温/查询
  定时上报日志
```

## 目录结构

```
智能冰箱/
├── Hardware/   # 外设驱动（BEEP、DHT11、Encoder、OLED、PWM、Serial、Key 等）
├── User/       # 应用代码（main.c、stm32f10x_it.c）
├── library/    # 标准外设库
├── start/      # 启动文件
├── system/     # 系统文件
├── RTE/        # 运行时环境
└── project.uvprojx  # Keil 工程文件
```
