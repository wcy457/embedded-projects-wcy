# 智能锁项目

基于 STM32F103C8T6 的智能门锁，支持密码、指纹、RFID 卡、蓝牙多种开锁方式，采用状态机架构，配置存储于 EEPROM，集成语音播报。

## 硬件平台

- **MCU**：STM32F103C8T6（标准外设库 StdPeriph_Driver）
- **指纹模块**：MG200（USART2）
- **RFID 模块**：MFRC522（SPI2）
- **触摸按键**：BS8116A（I2C，PB6-SCL/PB7-SDA）
- **显示**：OLED（模拟 SPI）
- **语音模块**：DATA(PB0)、BUSY(PB1)
- **存储**：AT24C04 EEPROM（I2C）
- **执行**：门锁电机（LOCK+ PA4 / LOCK- PA5）
- **通信**：蓝牙（USART3）、USART1 调试
- **时钟**：内部 RTC

## 功能特性

### 多种开锁方式
| 方式 | 说明 |
|---|---|
| 密码 | 6 位开门密码，错误 3 次触发报警锁定 30 秒 |
| 指纹 | MG200 模块 1:N 比对，支持登记/删除 |
| RFID 卡 | MFRC522 读卡，最多注册 5 张，卡号存 EEPROM |
| 蓝牙 | USART3 远程控制（预留） |

### 状态机设计（13 种状态）
```
STATE_IDLE（待机显示时间）
  └─ #键 → STATE_MAIN_MENU（主菜单）
       ├─ 密码输入 → STATE_INPUT_PASSWORD → 开门/管理员登录
       ├─ 指纹比对 → STATE_FINGER_MATCH → 开门
       ├─ 刷卡比对 → STATE_CARD_MATCH → 开门
       └─ 管理员登录 → STATE_ADMIN_MENU
            ├─ 修改管理员密码
            ├─ 设置开门密码
            ├─ 登记指纹
            ├─ 登记门禁卡
            ├─ 删除指纹
            └─ 修改时间
```

### EEPROM 配置存储
| 地址 | 内容 |
|---|---|
| 0x00 | 管理员密码（6 字节） |
| 0x10 | 开门密码（6 字节） |
| 0x20 | 门禁卡号（4 字节 × 5 张） |
| 0x40 | 已注册卡数量 |
| 0x50 | 初始化标志（0xA55A） |

### 安全机制
- 密码错误 3 次 → 语音报警 + LED 闪烁 + 蓝牙告警 + 锁定 30 秒
- EEPROM 首次运行初始化标志，掉电不丢失配置
- 卡号去重检查

